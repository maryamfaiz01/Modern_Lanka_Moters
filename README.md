## 📖 Overview

Modern Lanka Motors provides an interactive, mobile-responsive online storefront showcasing automobile spare parts and accessories across various categories:

- **Steering Wheels & Covers**
- **Seat Sets & Ergonomic Upgrades**
- **Sun Visors & Wind Deflectors**
- **Wiper Blades & Assemblies**
- **Brake Boosters & Braking Systems**
- **Cargo Carriers & Roof Racks**

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/maryamfaiz01/Modern_Lanka_Moters.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd Modern_Lanka_Moters
   ```
3. **Open in browser:**
   - Double-click [`index.html`](index.html), or
   - Use VS Code **Live Server** extension to preview with hot-reload.
